# SynchroLink: SIH Problem Statement Compliance & Innovation Report

**Project Title:** SynchroLink — AI-Powered Multi-Discipline EPC Schedule Progress Intelligence Engine  
**Target Solution:** Automated Ingestion, Hierarchical Constrained Linking (HCL), WhatsApp Gateway, Primavera P6 Sync, and RLHF Institutional Memory for L1–L6 Infrastructure Projects.

---

## 1. Executive Summary & Problem-Solution Matrix

Large-scale Engineering, Procurement & Construction (EPC) infrastructure projects suffer from a fundamental disconnect: **macro/micro schedules (L1–L6) created in Primavera P6 or MS Project vs. fragmented, unstructured daily progress reports generated by field supervisors across disciplines (Civil, Mechanical, Piping, Electrical, Instrumentation, HSE)**.

SynchroLink solves this by bridging unstructured multi-channel inputs (WhatsApp text/audio notes, Hindi/Hinglish voice notes, Excel DPRs, site diaries) with granular L5/L6 project schedules using a **Hierarchical Constrained Linking (HCL)** engine, **Pydantic EPC validation**, **Oracle Primavera P6 bidirectional sync**, and an **RLHF Institutional Memory Bank**.

## 3. What Are We Uniquely Doing? (Key Innovations & Edge Features)

Beyond the baseline requirements, SynchroLink introduces several cutting-edge innovations that distinguish it from standard hackathon prototypes:

### 🌟 1. WhatsApp Business AI Bot with Live Webhook Simulator
- Site supervisors on active construction sites do not open heavy desktop software; they use **WhatsApp**.
- SynchroLink provides a production-grade webhook (`/api/whatsapp/webhook`) that handles text, audio notes, and media.
- The bot replies in seconds with formatted markdown tickets (`✅ Progress Synced to MECH-CDU2-P204-002: 80%` or `⏳ Ticket TRG-1159FE33 Sent to Planner Triage`).
- Built-in interactive **Smartphone Simulator** directly inside the Web UI for instant live demonstrations.

### 🌟 2. Indic NLP Dialect & Slang Normalization Engine
- Real Indian EPC sites communicate in **Hinglish/Hindi technical slang** (*"CDU Unit 2 mein P-204 pump installation 80 percent complete ho gaya, material nahi aane se 2 din delay hua"*).
- The extraction engine uses regex tokenization and phonetic fuzzy matching to accurately isolate:
  - **Asset IDs** (`P-204`, `V-101`, `HX-201`, `EP-07`)
  - **Plant Units** (`CDU-01`, `CDU-02`, `TANK-FARM`, `CONTROL-ROOM`)
  - **Scope Actions** (`FOUNDATION_PREPARATION`, `MECHANICAL_INSTALLATION`, `ALIGNMENT`, `CABLE_TERMINATION`, `HYDROTESTING`)
  - **Progress Percentages** and **Delay Days & 8 Standard Root Causes** (`MATERIAL_DELIVERY`, `LABOUR_SHORTAGE`, `EQUIPMENT_FAILURE`, `WEATHER`, etc.).

### 🌟 3. Hierarchical Constrained Linking (HCL) Engine
Rather than relying solely on naive semantic similarity (which confuses "P-204 Foundation" with "P-204 Alignment"), HCL enforces a multi-tier constraint model:
$$\text{Confidence} = 0.40 \cdot S_{\text{Asset}} + 0.25 \cdot S_{\text{Location}} + 0.15 \cdot S_{\text{Discipline}} + 0.10 \cdot S_{\text{Action}} + 0.10 \cdot S_{\text{Vector}} + \text{RLHF Boost}$$
This guarantees mathematical explainability for enterprise planners.

### 🌟 4. Continuous RLHF (Reinforcement Learning from Human Feedback) Memory Bank
- When a human planner resolves an ambiguous match in the Triage queue, SynchroLink doesn't just discard the decision—it writes the human reward ($+1.0$) into an **Institutional Memory Vector Bank**.
- Future field reports with similar phrasing or colloquial slang automatically receive an RLHF confidence boost, making the system self-learning over the project lifecycle.

### 🌟 5. Oracle Primavera P6 `.XER` & MS Project Bidirectional Exporter
- Unlike tools that output generic JSON, SynchroLink compiles the live schedule database into **native Oracle Primavera P6 `.XER` export format**, matching table definitions (`%T PROJECT`, `%T PROJWBS`, `%T TASK`), allowing immediate import into enterprise PMIS software.

### 🌟 6. Conversational Natural Language Delay Query Assistant
- Management can query project status conversationally: *"Why is P-204 pump delayed?"* or *"Show material delivery bottlenecks"*.
- The assistant analyzes graph delay events and responds with root cause distributions and impacted schedule days.

### Method B: Live Testing from Your Actual Physical WhatsApp Mobile Phone

To receive and process messages from your real WhatsApp app on your smartphone:

#### Step 1: Start a Secure Tunnel (e.g., ngrok or cloudflare)
In a terminal, expose your local port 8000:
```bash
ngrok http 8000
```
This gives you a public HTTPS URL like `https://abcdef123.ngrok-free.app`.

#### Step 2: Configure WhatsApp Business API / Twilio Webhook
1. In your **Twilio Console** (Programmable Messaging -> WhatsApp Sandbox) or **Meta WhatsApp Business Cloud API**:
2. Set the Webhook URL to:
   ```text
   https://abcdef123.ngrok-free.app/api/whatsapp/webhook
   ```
3. Set HTTP Method to `POST`.

#### Step 3: Send a WhatsApp Message from Your Phone
Open WhatsApp on your phone and send:
