# User Journeys

## Journey A --- Supervisor submits progress

1.  Supervisor opens Field Reports.
2.  Selects Text or Voice.
3.  Enters a natural-language progress statement.
4.  Clicks Process Report.
5.  Sees extraction progress.
6.  Reviews structured entities.
7.  Sees schedule match.
8.  If high confidence, update is synchronized automatically.
9.  Supervisor can inspect the resulting activity record.

## Journey B --- Planner reviews ambiguity

1.  Planner opens Planner Triage.
2.  Sees pending review count.
3.  Opens a low-confidence report.
4.  Reads original report.
5.  Reviews extracted entities.
6.  Reviews ranked candidate activities.
7.  Reads match explanation.
8.  Selects correct activity or rejects.
9.  Confirms decision.
10. System updates schedule only after approval.
11. Audit record is created.

## Journey C --- Manager investigates delay

1.  Manager opens Delay Intelligence.
2.  Reviews total delayed activities.
3.  Views delay root-cause distribution.
4.  Filters by discipline/plant.
5.  Opens a delay event.
6.  Traces it to the original field report.
7.  Sees schedule impact and historical occurrences.

## Journey D --- Evaluator demo

1.  Open Command Center.
2.  Submit high-confidence P-204 report.
3.  Show extracted entities.
4.  Show 94%-style high-confidence match.
5.  Show automatic Gantt update.
6.  Submit ambiguous pump-area report.
7.  Show low confidence.
8.  Show automatic sync blocked.
9.  Approve from Planner Triage.
10. Show audit trail.
11. Open Delay Intelligence.
