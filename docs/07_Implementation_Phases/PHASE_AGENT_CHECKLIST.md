# Agent Phase Checklist

Use this checklist during implementation.

## Every phase

-   [ ] Inspect existing implementation.
-   [ ] Read relevant documentation.
-   [ ] Plan file changes.
-   [ ] Implement.
-   [ ] Run formatter/linter.
-   [ ] Run type checker.
-   [ ] Run unit tests.
-   [ ] Run integration tests where applicable.
-   [ ] Launch application.
-   [ ] Use browser agent.
-   [ ] Verify relevant route.
-   [ ] Verify primary user action.
-   [ ] Check browser console.
-   [ ] Check network failures.
-   [ ] Fix regressions.
-   [ ] Update documentation if needed.
-   [ ] Record phase completion.

## Before moving forward

-   [ ] No critical test failure.
-   [ ] No critical browser error.
-   [ ] No dead button in affected area.
-   [ ] No fake success state.
-   [ ] No schedule mutation without audit.
-   [ ] No low-confidence auto-sync.

## Final regression

-   [ ] Clean database seed.
-   [ ] Golden high-confidence demo.
-   [ ] Golden low-confidence demo.
-   [ ] Planner approval.
-   [ ] Planner rejection.
-   [ ] Gantt update.
-   [ ] Delay analytics update.
-   [ ] Audit trail.
-   [ ] Application restart.
-   [ ] Browser refresh.
